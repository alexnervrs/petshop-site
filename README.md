# PetShop Amigo Fiel

Site institucional responsivo para um petshop, desenvolvido como projeto acadêmico no curso de Análise e Desenvolvimento de Sistemas da PUCRS.

## Páginas

| Página | Conteúdo |
| ------ | -------- |
| `index.html` | Página inicial com apresentação do petshop |
| `produtos.html` | Catálogo de produtos |
| `servicos.html` | Serviços oferecidos (banho, tosa e outros) |
| `contato.html` | Informações de contato |
| `cadastro.html` | Formulário de cadastro de cliente |
| `agendamento.html` | Formulário de agendamento de serviço com escolha de serviço, data e horário |

## Tecnologias

* HTML5
* CSS3
* Bootstrap 5.3 e Bootstrap Icons
* Google Fonts (Nunito e Poppins)

## Destaques

* Layout responsivo com navbar fixa e menu colapsável no celular
* Formulários com campos obrigatórios e atributos de acessibilidade (`aria-label`, `aria-required`)
* Navegação entre todas as páginas pelo menu

## Como abrir

Clone o repositório e abra o arquivo `index.html` no navegador:

```bash
git clone https://github.com/alexnervrs/petshop-site.git
```
